Module H · Target Output

RoboWorld 2026：把课程学习变成参赛产出

30–45 分钟 · 目标：能把前 12 课的方法训练转化为一个明确的 RoboWorld 项目包和提交计划。

RoboWorld 2026 Evaluation system Benchmark map

为什么要有目标活动

只学习概念容易停在“我看过论文、跑过 demo”。一个明确的外部产出会迫使你回答更实际的问题：任务是什么、指标是什么、baseline 在哪里、我的改进是否真的有效、别人能否复现。

本课程选择

主目标采用 RoboWorld Challenge 2026 · WorldNav：单张初始 RGB 图像和自然语言指令输入，输出完整未来导航轨迹。它同时覆盖 language grounding、world model、policy 和 trajectory evaluation，和课程主线最一致。

三个赛道的取舍

Track定位为什么选 / 不选
WorldNav主目标任务形式与课程最贴近：vision + language → future trajectory；允许 world model、VLA 和 policy-only 方法。
HA-VLN 2.0进阶目标闭环 RGB-D 导航、动态行人和 social compliance 很有价值，但系统复杂度更高。
SafeDrive-VLA观察目标world-model dreaming 与安全冲突很有启发，但训练数据约 1.2TB，不适合作为第一参赛目标。

完整对比见 RoboWorld 2026 参考页。

课程能力如何迁移

从 Cosmos 迁移

关注 future observation prediction 是否能帮助选择动作，而不是只生成好看的视频。

从 RSSM 迁移

用 rollout error vs horizon 检验想象稳定性，避免只看 teacher-forced loss。

从 SmolVLA 迁移

审计 action chunk、单位、坐标系、Stop 语义和 embodiment，不把接口跑通当作任务掌握。

从 PushT 迁移

把 episode-safe split、baseline、offline/closed-loop 证据阶梯带到官方数据审计。

产出路线

P0 Decision       阅读规则、注册、确认算力/存储、选择 WorldNav
P1 Reproduce       审计 schema、下载最小子集、复现 baseline
P2 Improve         只加入一个明确组件：语言编码 / 轨迹解码 / latent rollout / VLA adapter
P3 Validate        在 seen + unseen validation 上报告 SR、ATE、RPE、route fidelity
P4 Submit          生成官方格式预测、记录分数变化、写技术报告
P5 Archive         固化配置、seed、命令、失败案例和下一版计划

项目目录模板和详细检查表见 ROBOWORLD_2026_PLAN.md。

实践：写你的参赛立项页

  1. 创建 roboworld_2026/README.md。
  2. 写下团队、主赛道、方法路线和第一个 baseline。
  3. 列出输入张量、输出张量、单位和官方指标。
  4. 定义 P0–P5 里程碑和每阶段的可交付文件。
  5. 写出风险：数据下载、算力、动作空间、 unseen 泛化、提交格式。
  6. 明确失败判据：什么结果说明该组件没有价值。
完成标准

队友只读你的 README 和 run.sh，就能复现数据审计、baseline、validation 和提交文件生成流程。

证据边界

  • PushT 是二维 manipulation，WorldNav 是语言条件导航；本地结果不能预测官方排名。
  • WorldNav 是 open-loop trajectory evaluation；HA-VLN 才提供更强的闭环交互评估。
  • 官方页面当前只列时间线阶段，报名和提交前必须核对当届具体日期和规则。
  • 比赛排名是外部结果；课程产出以可复现实验、清晰报告和失败分析为准。
