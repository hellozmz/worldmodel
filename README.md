## 学习结构

课程采用「总—分—总—延伸」：

1. **总框架**：0001 先分清 world model、policy、VLA、benchmark。
2. **分线路**：0002–0011 依次学数据、视频/latent 世界模型、policy/VLA 与闭环评估。
3. **总收束**：0012–0014 把证据链整理成 capstone、RoboWorld 产出和 research portfolio。
4. **延伸补强**：0015–0016 补充 WAM / SuperMimic 前沿，以及无真机时的仿真实验流程。
