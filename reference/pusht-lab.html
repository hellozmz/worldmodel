三个不能犯的错

1. 随机按帧切分

相邻帧几乎重复，会造成验证集泄漏。必须按 episode 切分。

2. 只看 action MSE

离线误差低不代表闭环能推动 T 块。

3. 忽略 action 单位

这里是像素坐标，不是关节角度或末端位移。

和实验对应

  • Tiny imitation policy：state → action MLP。
  • Tiny RSSM：state/action 序列 → 下一状态、reward、done。
  • gym-pusht：闭环 return / coverage / success。
