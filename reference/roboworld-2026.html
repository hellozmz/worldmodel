RoboWorld Challenge 2026：课程目标产出

把 12 课的本地实验推进成一个可复现、可提交、可解释的参赛项目。

活动定位

RoboWorld Challenge 2026 关注机器人与自动驾驶中的 embodied world modeling，鼓励参赛者结合 world model、VLA 和 embodied policy，让智能体理解语言、预测未来状态并安全行动。官方说明它是与 RoboPAD @ NeurIPS 2026 相关的独立组织 challenge；challenge 参赛与 workshop 论文投稿是两条不同路径。

本课程的目标

不是空喊“参加比赛”，而是产出一个完整的 RoboWorld-ready project package：明确赛道、可复现 baseline、改进假设、验证结果、失败分析和官方提交记录。是否获奖是外生结果，不作为学习成功与否的唯一标准。

为什么优先 WorldNav

  1. 任务形式贴近课程主线：一张图 + 一句语言 → 未来动作轨迹，正好对应 perception、world model、policy 的边界。
  2. 允许不同层次方法：官方鼓励 world model、VLA 和 policy-only 方法；可以先做可复现 baseline，再逐步加入想象或 VLA 组件。
  3. 产出风险可控：相较 SafeDrive 约 1.2TB 压缩数据，WorldNav 更容易先完成数据审计、baseline 和消融。
  4. 评估指标可学习：SR/ATE/RPE 与本课程的评价体系直接衔接；full-route 和 heading fidelity 补充轨迹质量。
不要过度承诺

本地 PushT 是二维 manipulation，RoboWorld WorldNav 是语言条件导航。PushT 实验只提供方法训练，不能把 PushT 指标外推为 RoboWorld 排名。

最低合格产出

即使暂时不提交官方服务器，也至少要有：数据审计、可复现 baseline、一个改进假设、validation 指标、失败分析和完整报告。这样才能把学习成果沉淀下来。

五阶段里程碑

P0 · Decision

确认主赛道为 WorldNav，阅读规则、注册、检查算力和存储。

P1 · Reproduce

下载数据或最小子集，审计 schema，复现官方/简单 baseline。

P2 · Improve

加入一个明确组件：语言编码、轨迹解码、latent rollout 或 VLA adapter。

P3 · Validate

在 seen/unseen validation 上报告 SR、ATE、RPE 和误差分析。

P4 · Submit

生成官方格式提交，记录分数变化；整理报告和复现包。

备选路线

  • HA-VLN 2.0：如果团队更关注 closed-loop、动态行人和 social navigation，可作为第二阶段目标。
  • SafeDrive-VLA：如果后续有足够存储、GPU 和自动驾驶经验，可研究 world-model dreaming 与安全冲突处理。
  • 非比赛路线：若官方规则或时间不合适，可把同一产出包投给开源 benchmark 复现报告、课程项目或内部技术分享。

官方事实与边界

  • WorldNav 使用 LCVN 数据：官方页写明 39,016 条轨迹和 117,048 条人工校验指令。
  • WorldNav 指标包括 SR、ATE、RPE、full-route fidelity、heading / turn fidelity。
  • HA-VLN 2.0 使用 RGB-D 和连续环境，成功要求距离目标 3m 内且无碰撞。
  • SafeDrive-VLA 训练数据约 1.2TB，评估包含 CARLA-F 和 B2D-C 两组路线。
  • 官方时间线当前只列出阶段，未在本页给出具体日期；报名和提交前必须查官网当届信息。
