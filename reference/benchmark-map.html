比赛与 Benchmark 地图

先选对任务族和指标，再决定是否参加 challenge 或提交 leaderboard。

Benchmark、leaderboard、challenge 的区别

Benchmark

固定任务集、数据划分和指标，用来做可复现比较。

Leaderboard

按指标排序的结果列表；要看是否固定 test split、是否允许外部数据和多次提交。

Competition / Challenge

有时间窗口、提交格式和排名规则；每年任务和数据可能变化，报名前看官方页面。

├─ 只想验证视频预测质量
│   └─ WorldModelBench / WorldArena + PSNR、SSIM、LPIPS、FVD、rollout
├─ 想做语言条件长时序操作
│   └─ CALVIN / LIBERO
├─ 想做多任务操作和 meta-learning
│   └─ Meta-World
├─ 想做导航或家庭任务
│   └─ AI Habitat / BEHAVIOR / Embodied AI Workshop
├─ 想测试真机部署
│   └─ RoboChallenge + 延迟、安全、鲁棒性
└─ 想从课程最小实验扩展
    └─ PushT 图像输入 / richer state / RSSM planning

参加比赛前的检查表

  1. 确认任务定义、观测空间、动作空间和 embodiment。
  2. 确认训练/验证/测试划分以及是否允许外部数据。
  3. 确认主指标、次要指标、成功判定和 tie-breaker。
  4. 确认提交格式、推理时间、硬件、网络和上传限制。
  5. 先复现官方 baseline，再改模型。
  6. 保留配置、seed、日志和可复现命令。
  7. 不要把验证集调优结果说成测试集泛化能力。
