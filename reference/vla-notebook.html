VLA / SmolVLA 速查本

从语言、图像、状态到动作块。

接口定义

input:
  observation.images.camera1
  observation.state
  task text
output:
  action chunk: (batch, 50, 6)

核心概念

Action chunk

一次输出未来多步动作，减少推理频率并保留短时序结构。

Flow matching

从噪声到动作分布学习速度场，而不是只回归单个均值动作。

VLM backbone

把视觉和语言语义带进动作预测。

Pre/post processor

图像、状态、动作归一化必须和训练分布一致。
